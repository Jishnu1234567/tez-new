# Old domain redirect (tezcoservices.com)

Upload both files in this folder to `public_html` of the **tezcoservices.com** hosting
(cPanel at Webhostbox). Every old URL then redirects permanently (301) to the same path
on https://thetezco.com. `index.html` is only a safety net if `.htaccess` rules are disabled.

Keep this redirect in place for at least 12 months and keep the old domain registered.
